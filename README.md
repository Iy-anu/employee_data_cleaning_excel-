# employee_data_cleaning_excel-
Excel data cleaning project involving text cleaning, nested formulas, and average age analysis.
project overview:
The project focuses on cleaning and analyzing employee data in excel. The dataset contained inconsistency such as extra spaces, inconsistenced, numbers aligned as text, and special symbols.
The objectives:
Clean inconsistent employee age data 
Correct wrong enteries in dataset
Convert text value into numeric format
Calculate the average employee age accurately 
The Excel Functions used in the data cleaning
SUBSTITUTE()
TRIM()
CLEAN()
VALUE()
IF()
AVERGE()
The Challenges i faced while cleaning the data 
One of the main challenges i faced was debugging nsted formulas, especially when handling hidden characters and converting tex to numbers correctly. The issue was resolved when i break the formula into smaller steps before nesting them together.
After cleaning the dataset properly, the average employee age was calculated: 
32.5
